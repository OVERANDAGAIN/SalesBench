## Known Issues / Protocol Debt

1. **失败传播语义后续需正式确认**。原 V1 保留成功前缀、业务失败后 skipped；没有把失败消息与末尾 purchase 重新解耦。
2. 仍是 TEST 的有限供应、即时采购/结算、共享库存、整数分报价、seeded resolution；没有正式排名/推荐/奖励、消费者模型、物流/退款/佣金/税费。
3. 这是工程手工输入界面，不是 HumanDriver 正式实验 profile、正式登录或真实模型；未提交持续等待，不能用自动 Wait 加快验收。
4. Polling 当前约每秒读取通知/观察/本人回执，优先清晰可靠，未做大规模优化或 WebSocket/SSE。UI 余额只展示已提交状态；报价和库存须等待 Engine 最终裁决。
5. sessionStorage 是轻量本机绑定/恢复材料；复制标签页可能继承原身份，需要明确切换。凭据文件不加密、不跨机同步；不是生产凭据治理方案。
6. 原平台的单 worker、完整历史重放、代码匹配、fencing 和故障保证/不保证范围保持不变；没有新增 HA、备份、规模测试或自动修复旧 trace。
7. Developer inspect 能看到全场账户/订单等私有信息，只在可信本机使用，不挂到参与者 UI。缺失的排名/初始资金字段保持 null/未发布，不通过私有数据补造公共统计。
8. 本轮尚未由用户亲自验收新的 network 操作体验；自动浏览器结果不能代替用户确认。已有未运行 session 可直接按指南开始。
